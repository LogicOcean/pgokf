Identity provider{% if provider.configured %} ({% if provider.enabled %}on{% else %}off{% endif %}){% endif %}

Let people sign in with the identity provider they already have beside this site's own passwords: any OpenID Connect provider (Entra ID, Okta, Keycloak, Auth0, Google…), or GitHub. Register this site with the provider using the callback URL below, then enter what it gave you. Saving reaches the provider first - its discovery document, or GitHub's API - so a wrong issuer is refused before anything is stored. People who sign in this way appear under People at their first sign-in, without a password and at the bottom of the ladder: on every request they hold the higher of the role set there and the role their groups map to (those in no mapped group get the role of everyone else), so a group taken away at the provider takes its role away here. Removing one of them ends their sessions but is not a ban: they get a fresh row at their next sign-in. A name that signs in here with a password is never signed in through the provider.

GitHub: create an OAuth App (Settings → Developer settings) with this callback URL and enter its client id and secret (GitHub cannot complete a sign-in without one); leave the issuer empty for github.com or name your GitHub Enterprise Server; scopes read:user user:email read:org; the identity claim sub is the account's numeric id (stable), login the user name (which GitHub lets people change and later hands to someone else - keep sub unless you accept that); groups are the organizations and org/team slugs the person belongs to, so a role map reads my-org=editor,my-org/maintainers=approver. An organization that restricts third-party access lists itself only once it has approved the app.

MCP tokens{% if mcp_tokens_managed_here %} ({{ mcp_tokens.len() }}){% endif %}

An agent that cannot launch pgokf-mcp itself calls it over HTTP, and every such request carries a bearer token. A token is shown once, when it is minted; only its digest is kept, so it can be revoked here but never read back. A reader token searches and reads the catalog; a builder token may also build workspace plugins. A token is minted for the tenant this site serves, an MCP endpoint accepts only tokens minted for its own, and this page shows that tenant's tokens alone. Revoking takes effect with the next request.
